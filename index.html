How to use

  1. Choose Instruction or Exercise mode.
  2. Place your fingers on the home row: A S D F for left, J K L ; for right.
  3. Use each finger for its letters. Start slowly, then speed up.
  4. In Instruction mode you can turn the timer off.
  5. Only move to the next letter when you type the correct key.
  6. Listen for the click sound for correct keys.
Mode details
Instruction mode = step-by-step with unlimited time option.
Exercise mode = timed rounds, level progression, score and Game Over.
Tip: Keep your eyes on the screen. Type with the correct finger.
